Features

Everything you need. Nothing you don't.

Axe is a single-purpose tool built to do one thing exceptionally well.

⚡

Instant overlay

Axe pops up the moment you press your shortcut — no dock, no Command-Tab, no hunting.

🔒

No Accessibility needed

Uses a Carbon hot key — not a global event tap — so you never have to grant Accessibility permission.

🔍

Type to filter

Start typing an app name to instantly narrow the list. Your keyboard never leaves the home row.

☑️

Batch kill

Tick multiple checkboxes and nuke them all at once with a single confirm. One swing, many heads.

📊

Memory at a glance

See each app's resident memory so you know exactly which one is eating your RAM.

🗂

Workflow sessions

Save your current app layout as a named Workflow and restore it with one click — even on a fresh Space.

🖥

Restore on new Space

Switch to a new macOS Space and Axe instantly opens your Workflow apps there, leaving everything else untouched.

🎛️

Two interface styles

Choose between a floating Spotlight-style overlay or a compact menu bar popover — whatever feels right.

⌨️

Customisable shortcut

⌘Z is the default, but you can set any key combination in Settings with a single click.

Direct Download

Download the DMG, open it, and drag Axe to your Applications folder. No package manager required.

Download Axe.dmg

How to install

1
Download and open the DMG

Double-click Axe.dmg from your Downloads folder.

2
Drag Axe to Applications

Drag the Axe icon onto the Applications folder shortcut inside the DMG.

3
Launch and press ⌘Z

Open Axe from Applications or Spotlight. Press ⌘Z from anywhere to bring up the overlay.

For developers

Homebrew

Install via Homebrew for easy, one-command updates alongside the rest of your dev tools.

1
Install Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Already have Homebrew? Skip to step 2 →

2
Install Axe
brew install emerytech/axe/axe

This taps the emerytech/axe Homebrew tap and installs the cask automatically.

3
Update any time
brew update && brew upgrade axe

Run this whenever you want the latest version.
